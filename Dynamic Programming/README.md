## 🧠 Common DP Patterns

### 1. 1D Dynamic Programming
Problems where the current state depends on previous states.

### 2. 2D Dynamic Programming
Problems involving two changing parameters such as strings,
arrays, or grids.

### 3. Knapsack Pattern
Problems involving choices, capacities, and optimization.

### 4. Subsequence Pattern
Problems involving finding optimal subsequences from arrays
or strings.

### 5. String DP
Problems involving matching, transformation, or comparison
between strings.

### 6. Grid DP
Problems where states represent positions in a matrix or grid.

### 7. DP with Space Optimization
Reducing a 2D DP table to one or two rows when only previous
states are required.

## 🔍 DP Problem-Solving Framework

When approaching a Dynamic Programming problem:

1. **Define the State**
   - What does `dp[i]` or `dp[i][j]` represent?

2. **Identify the Choices**
   - What decisions can be made at the current state?

3. **Find the Transition**
   - How does the current state depend on previous states?

4. **Define Base Cases**
   - What are the smallest or initial states?

5. **Determine the Computation Order**
   - Top-Down or Bottom-Up?

6. **Optimize Space**
   - Can previous states be stored using fewer variables or arrays?

7. **Analyze Complexity**
   - Determine the time and auxiliary space requirements.
