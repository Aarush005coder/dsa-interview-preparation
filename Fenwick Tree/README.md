## 🎯 Learning Goals

- Understand the working principle of a Fenwick Tree.
- Learn how to implement point updates and prefix sum queries efficiently.
- Understand the `idx & (-idx)` operation used to navigate the tree.
- Use two prefix queries to calculate a range sum.
- Learn coordinate compression to map large or negative values to valid indices.
- Combine prefix sums and a Fenwick Tree to solve range-sum counting problems.
- Understand why queries must be performed before inserting the current prefix sum.
- Write clean, optimized, and well-documented C++ solutions.
