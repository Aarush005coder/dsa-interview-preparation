## 📌 Concepts Covered

- Understand how greedy algorithms make the best local choice at each step.
- Learn how to identify problems where local decisions can lead to a globally optimal solution.
- Practice ordering choices based on their value or priority.
- Combine greedy strategies with sorting and other efficient techniques.
- Learn how to prove whether a greedy choice is safe for a given problem.
- Analyze the time and space complexity of greedy solutions.

## 🎯 Learning Goals

- Build a strong foundation in Greedy algorithms.
- Learn to recognize greedy patterns in different types of problems.
- Understand the reasoning behind greedy choices instead of relying only on implementation.
- Practice designing simple and efficient solutions.
- Write clean, optimized, and well-documented C++ solutions.
