# Recursion

This folder contains **Recursion** problems solved in **C++** as part of my DSA preparation. Each solution focuses on understanding recursive problem solving, defining base cases, reducing the problem size, and analyzing time and space complexity.

## 📌 Concepts Covered

- Understand how a problem can be divided into smaller subproblems.
- Learn how to define clear and correct base cases.
- Practice reducing the input size in every recursive call.
- Understand how the call stack stores recursive function states.
- Learn how recursion can simplify mathematical and algorithmic problems.
- Practice combining recursion with techniques such as Binary Exponentiation.

---

## 🎯 Learning Goals

- Build a strong understanding of recursive problem solving.
- Learn how to identify suitable base cases and recursive cases.
- Improve the ability to convert mathematical formulas into recursive solutions.
- Understand recursion depth and stack space.
- Learn when recursion can provide a simpler or more efficient solution.
- Write clean, optimized, and well-documented recursive C++ solutions.
