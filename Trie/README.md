## 🚀 Why Trie?

A **Trie (Prefix Tree)** is a tree-based data structure used to store strings efficiently.

Each node represents a character, and the path from the root to a node forms a prefix of one or more words.

Trie is particularly useful when dealing with:
- Prefix searching
- Dictionary implementations
- Auto-complete systems
- Spell checking
- Word search problems
- String matching

Compared to repeatedly comparing entire strings, a Trie allows common prefixes to be shared, making many string operations significantly faster.

---

## 📂 Trie Node Structure

A typical Trie node contains:

- Character data
- Array (or map) of child pointers
- Terminal flag (`isTerminal`)
- Additional metadata (optional), such as:
  - Prefix count
  - Word count
  - Frequency
