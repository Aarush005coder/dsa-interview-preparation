## 🚀 Why Two Pointers?

The Two Pointers technique uses two indices to process data efficiently instead of checking every possible pair.

It is commonly used for:
- Finding pairs with specific conditions.
- Removing duplicates from sorted arrays.
- Comparing elements from both ends.
- Optimizing searching and traversal problems.

This technique helps reduce time complexity and is one of the most important patterns for solving array and string problems.
